# I-SABY PWA v0.21

- Massa inseribile sotto 900 kg; tolta la soglia rigida dal motore geometrico.
- Famiglia rossa prolungata linearmente con tratteggio oltre l’estremità digitalizzata.
- Le proiezioni sono semplici estrapolazioni geometriche, non prestazioni validate.
- Per masse estremamente basse, combinazioni incompatibili o distanze fuori scala il motore può comunque non produrre un risultato.
- Nessuna modifica a W&B, vento, quota, note pista, dichiarazioni POH e ±2% (solo campione).

**NON VALIDATO PER USO OPERATIVO**. Fare riferimento al POH applicabile a I-SABY.
